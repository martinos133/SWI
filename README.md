# Žiadosť o ubytovanie

Webová aplikácia na podávanie a spracovanie žiadostí o ubytovanie na univerzitných
internátoch. Plán a stav prác je v [PLAN.md](PLAN.md).

## Spustenie

```bash
npm install
cp .env.example .env   # a nastav APP_SECRET
npm run dev
```

Aplikácia beží na <http://localhost:3000>.
